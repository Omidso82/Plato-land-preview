# گزارش تغییرات پنل گزارش پیش‌بینی قهرمان سری دوم

نسخه: 1.0  
تاریخ: 2026-11-07  
محدوده: PLATO LAND – Temporary Projects  
وضعیت: پیاده‌سازی در شاخه مستقل؛ در انتظار CI و بازبینی/انتشار

## هدف
افزودن امکان مشاهده فهرست رأی‌های پیش‌بینی قهرمان سری دوم در پنل موقت مدیریت، شامل Plato ID رأی‌دهنده، Plato ID بازیکن انتخاب‌شده و زمان ثبت رأی.

## محل دسترسی
پنل موجود: https://platoland.org/?page=admin  
بخش جدید پنل مالک: «پیش‌بینی قهرمان سری دوم»

## رفتار رابط
- نمایش تعداد کل رأی‌ها و وضعیت باز/بسته بودن پیش‌بینی.
- نمایش فهرست رأی‌ها با ستون‌های رأی‌دهنده، قهرمان انتخاب‌شده و زمان ثبت.
- مرتب‌سازی از جدیدترین رأی به قدیمی‌ترین.
- تازه‌سازی خودکار هر ۱۰ ثانیه و دکمه تازه‌سازی دستی.
- نمایش زمان با منطقه زمانی دستگاهی که پنل را باز کرده است.
- طراحی جدول با پیمایش افقی در صفحه‌های کوچک.

## امنیت و منبع داده
- گزارش از مسیر موجود GET تابع Edge با action=report دریافت می‌شود.
- تابع Edge قبل از بازگرداندن داده، نشست کاربر را اعتبارسنجی و نقش owner را از جدول user_roles بررسی می‌کند.
- بخش جدید فقط در منوی مالک (canManage) نمایش داده می‌شود؛ اعتبارسنجی سمت سرور همچنان مرجع نهایی مجوز است.
- اطلاعات رأی‌ها مستقیماً از مرورگر و جدول عمومی خوانده نمی‌شوند.
- هیچ دسترسی عمومی جدیدی به جدول رأی‌ها داده نشده است.

## فایل‌های تغییر یافته
- src/App.tsx — افزودن گزینه منوی مالک و اتصال کامپوننت گزارش.
- src/Series2PredictionReport.tsx — دریافت امن گزارش، نمایش فهرست و تازه‌سازی ۱۰ ثانیه‌ای.
- src/Series2PredictionReport.css — استایل واکنش‌گرا.
- این سند — ثبت تغییرات.

## اثرات و محدودیت‌ها
- هیچ migration، تغییر schema، تغییر RLS، تغییر Edge Function یا نوشتن در دیتابیس انجام نشده است.
- داده‌های رأی، ثبت‌نام، گروه‌بندی، برنامه و نتایج مسابقه تغییر نمی‌کنند.
- بخش گزارش فقط برای مالک کل در پنل مدیریت موجود است.
- تازه‌سازی ۱۰ ثانیه‌ای polling است، نه Supabase Realtime؛ بنابراین نمایش تغییرات ممکن است حداکثر تا فاصله یک چرخه تأخیر داشته باشد.
- زمان نمایش‌داده‌شده بر اساس منطقه زمانی دستگاه مالک است؛ زمان خام ذخیره‌شده در دیتابیس دست‌نخورده می‌ماند.

## تست و وضعیت انتشار
- نتیجه CI و Build پس از ایجاد Pull Request باید ثبت شود.
- تا پیش از ادغام و موفقیت فرایند انتشار، قابلیت روی سایت زنده در دسترس نیست.
- پس از انتشار، ورود به پنل با حساب مالک و مشاهده فهرست رأی‌ها باید عملاً بررسی شود.
