## 1. هدف و ماهیت صفحه

این صفحه برای پیش‌بینی قهرمان سری اول مسابقات تخته‌نرد PLATO LAND ایجاد شده است. صفحه یک تجربه موقت و مستقل در دامنه اصلی است و نباید به‌عنوان بخش دائمی پلتفرم تلقی شود.

- عنوان: «پیش‌بینی قهرمان سری اول تخته پلاتولند»
- رابط فارسی و راست‌چین (RTL)، طراحی تیره با جزئیات طلایی و مناسب موبایل.
- هنگام نمایش صفحه موقت، بازدیدکننده فقط همین صفحه را می‌بیند؛ منو، هدر، فوتر یا بخش‌های دیگر سایت نمایش داده نمی‌شوند.
- کاربر اعلام کرده صفحه آماده شده و لینک آن را برای گروه ارسال کرده است.
- تصاویر بازیکنان عمداً به صفحه اضافه نشده‌اند؛ کارت‌های بدون تصویر مورد قبول مالک‌اند.
- این قابلیت برای پیش‌بینی است، نه ثبت‌نام در مسابقات و نه ثبت نتیجه رسمی مسابقه.

## 2. متن اطلاع‌رسانی و روش مشارکت

متن اطلاع‌رسانی مورد توافق:

«شرکت در این پیش‌بینی مخصوص اعضای گروه PLATO LAND است. برای ثبت پیش‌بینی، باید عضو و در گروه PLATO LAND فعال باشید. عضویت و فعال بودن شما توسط Owner و مدیریت گروه PLATO LAND بررسی خواهد شد.»

گردش کار:
1. شرکت‌کننده Plato ID خود را وارد می‌کند.
2. فقط یک بازیکن را انتخاب می‌کند.
3. ثبت‌نام/ورود حساب کاربری برای این صفحه لازم نیست.
4. هر Plato ID فقط یک رأی می‌تواند ثبت کند.
5. بررسی عضویت و فعال بودن Plato ID در گروه، به‌صورت انسانی توسط Owner و مدیریت گروه انجام می‌شود؛ سامانه صرفاً Plato ID و انتخاب را ثبت می‌کند.
6. آمار و نتیجه زنده برای عموم نمایش داده نمی‌شود.
7. فقط Owner مجاز است فهرست Plato ID رأی‌دهندگان و انتخاب‌هایشان را مشاهده کند.

- RLS فعال است و دسترسی مستقیم عمومی به جدول برای نقش‌های `anon` و `authenticated` اعطا نشده است.

### Edge Function ثبت رأی
نام: `plato-land-prediction-vote`

رفتار ثبت‌شده:
- درخواست POST را می‌پذیرد.
- CORS فقط برای `https://platoland.org` تنظیم شده است.
- ورودی را اعتبارسنجی می‌کند و بازیکن را از mapping داخلی معتبر تعیین می‌کند.
- مهلت پایان رأی‌گیری را در سمت سرور بررسی می‌کند.
- از service role فقط در backend برای درج رأی استفاده می‌کند؛ کلید محرمانه نباید در frontend قرار بگیرد.
- خطای unique constraint با کد `23505` به پاسخ HTTP 409 تبدیل می‌شود.
- endpoint عمومی برای خواندن فهرست رأی‌ها ایجاد نشده است.

### Edge Function مشاهده رأی‌ها توسط Owner
نام: `plato-land-prediction-owner-votes`

رفتار ثبت‌شده:
- فقط GET را می‌پذیرد.
- توکن نشست با `db.auth.getUser(token)` اعتبارسنجی می‌شود.
- نقش کاربر از `user_roles` خوانده می‌شود.
- فقط نقش `owner` یا `مالک کل` مجاز است.
- کاربر غیرمجاز پاسخ 403 و نشست نامعتبر پاسخ 401 می‌گیرد.
- CORS فقط برای دامنه اصلی است.
- این endpoint عمومی نیست.

مسیر پنل Owner در React: `/prediction-admin`.

نکته آزمون: کد Edge Function بررسی شده است؛ با این حال، در آخرین وضعیت مستندشده تست زنده کامل endpoint با نشست Owner و نشست غیرOwner هنوز تأیید نشده بود. این مورد را نباید بدون اجرای آزمون به‌عنوان تست موفق اعلام کرد.

## 7. حریم خصوصی و امنیت

- فهرست رأی‌دهندگان و انتخاب‌ها فقط برای Owner است.
- نتایج زنده یا تعداد رأی‌ها برای عموم منتشر نمی‌شود.
- از IP یا device fingerprint برای شناسایی رأی‌دهنده استفاده نمی‌شود.
- از لاگ درخواست‌ها به‌تنهایی نباید هویت یا رأی یک شخص را استنتاج کرد.
- فقط رکوردهای موفق ذخیره‌شده در جدول رأی‌ها رأی قطعی محسوب می‌شوند؛ درخواست‌های ناموفق/ردشده در شمارش رأی‌ها قرار نمی‌گیرند.
- هیچ service-role secret یا کلید محرمانه‌ای نباید در کد سمت مرورگر یا مستند عمومی قرار گیرد.

## 8. دستور قطعی مالک درباره موقت بودن صفحه و پایان عمر آن

مالک صریحاً تأیید کرده است که این صفحه **موقت** است و نباید اختلالی در روند عادی سایت ایجاد کند.

هنگامی که مهلت و کاربرد صفحه تمام شد:
1. صفحه فقط پس از دستور صریح مالک غیرفعال شود؛ غیرفعال‌سازی خودکار یا بدون اجازه ممنوع است.
2. غیرفعال‌سازی به معنی حذف صفحه نیست.
3. کد، طراحی، تنظیمات لازم و امکان استفاده مجدد باید حفظ شوند.
4. جدول و رکوردهای رأی، سوابق و اطلاعات لازم برای آرشیو/استفاده آینده حذف نشوند.
5. پس از غیرفعال‌سازی، مسیر عمومی پیش‌بینی برای بازدیدکننده عادی قابل دسترسی نباشد.
6. صفحه در آینده فقط با دستور Owner دوباره فعال شود.
7. منو، هدر، فوتر، صفحه اصلی، مسابقات، اخبار، ورود/ثبت‌نام، نقش‌ها و سایر قابلیت‌های اصلی سایت نباید به‌خاطر این صفحه تغییر نامطلوب کنند.
8. هیچ تغییر در schema، policy، جدول‌ها، احراز هویت یا داده‌های عملیاتی نامرتبط مجاز نیست.
9. پیش از اجرا، روش غیرفعال‌سازی باید طوری انتخاب شود که فقط این قابلیت را از دسترس عمومی خارج کند و امکان rollback/فعال‌سازی مجدد باقی بماند.
10. پس از انجام کار، آزمون شود که مسیر موقت دیگر عمومی نیست و صفحات و گردش‌های اصلی سایت همچنان سالم‌اند.

**ممنوعیت‌ها:**
- حذف route/component یا فایل‌های این قابلیت به‌عنوان روش پایان کار.
- حذف جدول `plato_land_prediction_votes` یا پاک‌کردن رأی‌ها.
- حذف Edge Functionها یا secrets لازم برای استفاده مجدد، مگر با دستور جداگانه و صریح مالک.
- تغییر یا جایگزینی دیتابیس اصلی.
- دستکاری سایر صفحات یا تنظیمات عمومی سایت برای پنهان‌کردن این صفحه.
- انتشار تغییرات اضافی یا بازطراحی صفحه در زمان غیرفعال‌سازی، مگر با درخواست جداگانه مالک.
