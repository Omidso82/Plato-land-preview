## موارد باقی‌مانده / محدودیت مهم
- ۱۸ تصویر اصلی قوانین به‌صورت فایل‌های مستقل و قابل استفاده در محیط اجرایی فعلی در دسترس نبودند. صفحه فعلاً جایگاه‌های مشخص‌شده برای ۱۸ تصویر دارد و **تصاویر رسمی در آن نمایش داده نمی‌شوند**.
- بنابراین این نسخه برای بازبینی ظاهر و جریان فرم اولیه است؛ هنوز نسخه نهایی مطالعه قوانین و آماده ثبت‌نام عمومی محسوب نمی‌شود.
- تست Build و TypeScript در این اجرا انجام نشده است؛ GitHub Actions run برای merge commit گزارش نشد.
- انتشار خودکار دامنه و بازشدن مسیر زنده از این محیط قابل تأیید نبود.
- هیچ ارسال واقعی با Plato ID انجام نشد تا رکورد آزمایشی وارد جدول ثبت‌نام نشود.

## پنل خصوصی بارگذاری تصاویر اسلایدها — ۲ نوامبر ۲۰۲۶
- مسیر خصوصی مالک: `/series2-slides-manager`. این مسیر در صفحه عمومی لینک، منو، هدر یا فوتر ندارد و فقط پس از ورود و تأیید نقش `owner` قابل استفاده است.
- پنل امکان انتخاب دقیقاً ۱۸ تصویر JPG/PNG/WEBP (حداکثر ۱۰ مگابایت برای هر تصویر) و اتصال ترتیبی آن‌ها به اسلایدهای ۰۱ تا ۱۸ را فراهم می‌کند.
- فایل‌ها در Storage همان پروژه متصل به سایت با شناسه `dfrppbapaaydbjeflozw` و bucket اختصاصی `series2-slides` ذخیره می‌شوند. Bucket عمومی فقط برای خواندن تصاویر قوانین است؛ سیاست‌های INSERT/UPDATE/DELETE فقط نقش owner را مجاز می‌کنند.
- هیچ جدول جدیدی ساخته نشد و داده‌های ثبت‌نام یا سایر جداول تغییر نکردند. یک bucket و چهار policy در Storage همان پروژه اصلی اضافه شد.
- صفحه عمومی از Storage فهرست تصاویر را می‌خواند و تصویر اصلی را با `object-fit: contain` نمایش می‌دهد؛ بنابراین تصویر بریده نمی‌شود.
- فرم پذیرش قوانین و ورود Plato ID تا رسیدن به اسلاید ۱۸ پنهان است. در اسلاید ۱۸ فقط دکمه «قبلی» نمایش داده می‌شود و دکمه «قانون بعدی» وجود ندارد.
- صفحه موقت ثبت‌نام سری دوم طبق تصمیم مالک فقط تا جمعه ۶ نوامبر ۲۰۲۶ فعال می‌ماند. پس از پایان ثبت‌نام باید این مسیر موقت غیرفعال و صفحه اصلی PLATO LAND بازگردانده شود.
- تغییرات کد در commitهای متوالی ثبت شده‌اند؛ deployment و تست نهایی build/دامنه هنوز باید تأیید شوند. تصاویر واقعی هنوز توسط مالک از پنل بارگذاری نشده‌اند.


## اصلاح پنل اسلایدها — بارگذاری مستقل هر جایگاه (۲ نوامبر ۲۰۲۶)

- روش انتخاب دسته‌جمعی ۱۸ فایل حذف شد؛ ترتیب فایل‌ها یا ترتیب انتخاب دیگر در تعیین شماره اسلاید دخالت ندارد.
- پنل خصوصی مالک اکنون ۱۸ جایگاه مستقل دارد. هر جایگاه شماره اسلاید، پیش‌نمایش تصویر، انتخاب فایل و دکمه ذخیره/جایگزینی مخصوص خودش را دارد.
- هر تصویر در Storage اصلی با کلید ثابت `slides/01` تا `slides/18` ذخیره می‌شود؛ پسوند و نام فایل اصلی در تعیین شماره نقشی ندارند.
- جایگزینی یک تصویر فقط همان شماره را به‌روزرسانی می‌کند. هنگام ذخیره، فایل‌های قدیمی همان شماره از روش قبلی پاک می‌شوند تا با نسخه جدید تداخل نداشته باشند.
- صفحه ثبت‌نام، کلیدهای ثابت جدید را بر فایل‌های قدیمی پسونددار اولویت می‌دهد و همچنان می‌تواند فایل‌های قبلی را تا زمان جایگزینی نمایش دهد.
- این تغییر فقط کد پنل و خواندن اسلایدها را تغییر می‌دهد؛ دیتابیس اصلی، جداول ثبت‌نام و داده‌های ثبت‌نام دست‌نخورده باقی مانده‌اند.
- پس از انتشار این نسخه، مالک هر اسلاید را جداگانه بارگذاری می‌کند؛ لازم نیست هر ۱۸ تصویر را یک‌باره انتخاب کند.
