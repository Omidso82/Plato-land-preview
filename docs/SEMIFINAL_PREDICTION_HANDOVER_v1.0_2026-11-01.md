# تحویل صفحه پیش‌بینی صعودکنندگان به فینال — سری اول لیگ تخته PLATO LAND

تاریخ: ۱ نوامبر ۲۰۲۶

## هدف و مسابقات
این نسخه صفحه موقت پیش‌بینی را از پیش‌بینی قهرمان به پیش‌بینی برنده دو مسابقه نیمه‌نهایی تغییر می‌دهد. شرکت‌کننده باید برنده هر دو بازی را انتخاب کند تا پیش‌بینی صعودکنندگان به فینال ثبت شود.

- نیمه‌نهایی اول: رامش (Plato ID بازیکن: 95m) در برابر سعید (Plato ID بازیکن: _34EED)
- نیمه‌نهایی دوم: هانا (Plato ID بازیکن: HANA1272) در برابر لاوین (Plato ID بازیکن: LVIN)

## مسیرها
- صفحه عمومی: https://platoland.org/semifinal-prediction
- گزارش خصوصی مالک: https://platoland.org/prediction-admin

## قوانین ثبت
- شرکت‌کننده Plato ID خود را وارد می‌کند.
- باید برای هر دو نیمه‌نهایی دقیقاً یک برنده انتخاب کند.
- هر Plato ID پس از نرمال‌سازی فقط یک بار مجاز به ثبت پیش‌بینی است.
- ثبت پس از ارسال قابل تغییر نیست.
- هیچ deadline یا ساعت پایان در این نسخه تعیین نشده؛ دریافت رأی تا زمان توقف صریح Owner باز می‌ماند.
- آمار عمومی نمایش داده نمی‌شود؛ فقط Owner گزارش کامل را می‌بیند.

## جداسازی داده‌ها و حفظ سوابق
- جدول قبلی `public.plato_land_prediction_votes` و تمام ۱۸ رأی قبلی دست‌نخورده حفظ می‌شوند.
- پیش‌بینی‌های جدید در جدول مستقل `public.plato_land_semifinal_prediction_votes` ذخیره می‌شوند.
- جدول جدید RLS فعال دارد و دسترسی مستقیم `anon` و `authenticated` به آن revoke شده است؛ فقط Edge Functions با service role آن را می‌خوانند/می‌نویسند.
- Edge Functionهای جدید:
  - `plato-land-semifinal-prediction-vote`
  - `plato-land-semifinal-prediction-owner-votes`
- پنل مالک دو نما دارد: پیش‌بینی نیمه‌نهایی‌ها و آرشیو پیش‌بینی قهرمان قبلی.
