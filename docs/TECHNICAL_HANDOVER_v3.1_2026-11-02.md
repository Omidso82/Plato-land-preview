## 4. وضعیت واقعی Storage در Supabase اصلی

Bucket موجود: `series2-slides`

تنظیمات مشاهده‌شده:

- `public = true`؛ این Bucket فقط برای تصاویر قوانین عمومی است تا صفحه ثبت‌نام بتواند آن‌ها را نمایش دهد.
- حداکثر حجم هر فایل: ۱۰ مگابایت.
- MIMEهای مجاز: `image/jpeg`، `image/png`، `image/webp`.
- خواندن عمومی برای نقش‌های `anon` و `authenticated` مجاز است.
- INSERT، UPDATE و DELETE برای این Bucket فقط با نقش `owner` در `user_roles` مجاز شده‌اند.

نتیجه Query مستقیم `storage.objects` در ۲ نوامبر ۲۰۲۶:

- تعداد کل اشیای Bucket: ۱۸.
- تعداد کلیدهای canonical شماره‌دار: ۱۸.
- تعداد کلید غیرمنتظره یا شماره تکراری: صفر.
- نام کلیدها دقیقاً از `slides/01` تا `slides/18` است.
- هر ۱۸ فایل دارای MIME نوع `image/png` و اندازه غیرصفر حدود ۲٫۰ تا ۲٫۳۴ مگابایت هستند.
- زمان ایجاد فایل‌ها به ترتیب شماره اسلاید از حدود ۱۷:۴۷ تا ۱۷:۵۵ UTC در ۲ نوامبر ۲۰۲۶ ثبت شده است.

این داده‌ها وجود ۱۸ فایل واقعی و شماره‌گذاری‌شده در Storage را تأیید می‌کنند؛ اما به‌تنهایی محتوای بصری هر تصویر را با فایل اصلی ارسالی مالک تطبیق نمی‌دهند. تأیید بصری ۱۸ تصویر همچنان باز است.
